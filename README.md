# Avondmenu website

Klaar voor GitHub Pages.

## Publiceren
1. Maak op GitHub een repository, bijvoorbeeld `avondmenu`.
2. Upload **de inhoud van deze map** naar de hoofdmap van de repository.
3. Ga naar **Settings → Pages**.
4. Kies **Deploy from a branch**.
5. Selecteer **main** en **/root**, en sla op.
6. De site verschijnt daarna op `https://<gebruikersnaam>.github.io/avondmenu/`.

De site is volledig statisch: geen server, database of API nodig.
