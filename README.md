# WeekMenu v3.7
- 80 Nederlandse hoofdgerechten met ingrediënten, bereidingsstappen en boodschappenlijst.
- Voor alle eerste 80 gerechten is een lokale foto geselecteerd uit de door de gebruiker aangeleverde fotos.zip.
- De foto's zijn opgenomen in assets/images en recipes.json verwijst rechtstreeks naar deze lokale bestanden.
- De 80 bestaande salades blijven behouden.
- FOTO_KOPPELINGEN.csv bevat per gerecht het oorspronkelijke fotobestand zodat een koppeling eenvoudig gecontroleerd of gewijzigd kan worden.
